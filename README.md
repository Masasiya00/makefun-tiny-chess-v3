A 4 KB chess engine for the make.fun tiny-chess-01 competition: 0x88 board, alpha-beta with iterative deepening on a fixed node budget, quiescence with check evasions, transposition table, MVV-LVA + killer + history ordering, tapered PeSTO-style evaluation with verified colour-mirror symmetry, and prepared defenses for the 15 practice openings.

## Run it

```sh
python3 -P -s main.py
```
